# C Basic Exercises

Collection of simple C programming exercises developed during college.

These programs were created as practice to improve logic, syntax and basic programming concepts in C.

## Projects included

- **OPR.c** — Basic operations practice
- **kabum.c** — Simple C program exercise
- **paventureiro.c** — Adventure-themed logic exercise
- **testenota.c** — Student grade/notes system

## Purpose

This repository gathers early college exercises focused on:
- Basic syntax and structure in C
- Conditional statements and loops
- Simple data handling
- Logic building

## Technologies

- C

## Note

These are beginner-level exercises created for learning purposes.
