
# C College Exercises

Collection of basic C programming exercises developed during college.

These programs were created to practice logic, conditionals, and basic data handling in C.

## Projects included

- **product-price-comparison.c**  
  Compares the market prices of the same product from two different sources (A and B) and indicates which one is higher.

- **grade-concept-system.c**  
  Receives a numerical grade and returns the corresponding concept (evaluation) based on the value entered.

- **age-verification.c**  
  Asks for the user's age and checks whether the person is of legal age or underage.

- **state-comparison.c**  
  Compares data from two different states and determines which one has better results based on the values provided.

## Purpose

These exercises were developed to practice:
- Conditional statements
- Basic input and output
- Simple decision-making logic
- Data comparison

## Technologies

- C

These are beginner-level college exercises created for learning purposes.
